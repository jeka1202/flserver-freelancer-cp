FL ControlPanel Warehouse Actions v18

Уточнённая логика действий со склада:

1. На свой корабль
   - это действие только для текущего пилота;
   - направление: личный склад текущего пилота -> его собственный корабль;
   - на корабль другого игрока передавать нельзя;
   - пока кнопка отключена до подключения FLHook/addcargo;
   - будущая логика: проверка свободного места -> addcargo -> списание со склада.

2. Передать пилоту
   - это только склад -> склад;
   - направление: личный склад отправителя -> личный склад получателя на этой же базе/планете;
   - корабль получателя не затрагивается;
   - .fl файлы не затрагиваются;
   - FLHook не вызывается.

3. Удалить
   - удаляет предмет только из SQLite-склада.

4. Свойства
   - показывает описание/характеристики из item_details после импорта DATA.

Запуск:
  py .\account_panel.py --accounts "c:\users\jeka1202\documents\my games\freelancer\accts\multiplayer" --ioncross "e:\[game]\freelancer\ioncross"

Импорт свойств предметов:
  py -m fl_panel.import_item_assets --data "e:\[game]\freelancer\data"
